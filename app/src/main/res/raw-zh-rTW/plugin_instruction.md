MCP Server 讓電腦上的 AI 用戶端 (例如 Claude Code, Cursor) 透過 [Model Context Protocol](https://modelcontextprotocol.io) 操作這支手機. 用戶端經 USB 或區域網路連線後, 可以藉助 AutoJs6 執行指令碼, 查看並操作介面, 擷取螢幕, 讀寫工作目錄中的檔案. 每個新用戶端首次呼叫都需要在手機上確認.

### 開始使用

1. 在 AutoJs6 抽屜中開啟 "MCP 伺服器" 開關, 首次使用時依提示啟用外掛.
2. 長按該項目, 或在 "外掛中心" 開啟本外掛的設定, 然後在 "用戶端設定" 中複製所用用戶端的設定, 加入電腦上的 MCP 用戶端.
3. 以 USB 連接電腦後, 在電腦上執行 "連線" 中的 adb forward 指令 (可點按 "複製 adb forward 指令" 複製).
4. 用戶端首次呼叫工具時, 在手機上點按 "允許" 確認配對.

### 主要功能

- **指令碼與介面**: 用戶端可以在 AutoJs6 中執行指令碼並讀取主控台輸出, 匯出無障礙節點樹, 尋找元件並點按, 輸入或捲動, 也可以擷取螢幕.
- **檔案與裝置**: 讀寫 AutoJs6 工作目錄中的檔案, 啟動應用程式, 讀寫剪貼簿. 開啟 "允許讀取共用儲存空間" 後, 還可以唯讀存取相簿與下載目錄等位置.
- **工具權限**: 依分組開關用戶端可用的工具, 關閉的分組不會出現在用戶端的工具清單中. "檔案刪除", "座標手勢" 與 "Shell 指令" 預設關閉.
- **外掛工具**: 安裝 OCR, Barcode, OpenCV 等外掛後, 用戶端可以辨識文字與條碼, 找圖找色. 其他外掛宣告的工具在 "外掛提供的工具" 中開啟.
- **已登記指令碼**: 以 `@agent` 註解登記的指令碼會列給用戶端, 模型可以依登記的參數執行它們; 需要先確認的指令碼由用戶端在執行前徵求你的同意.
- **權杖與配對**: 用戶端以存取權杖連線, 設定頁只顯示權杖末 4 碼. 在 "已配對用戶端" 中可以撤銷配對, "輪換權杖" 後舊權杖立即失效.
- **區域網路連線**: 開啟 "允許區域網路連線" 後, 同一網路中的電腦不需 USB 即可連線, 權杖與配對確認仍然有效.
- **閒置時自動停止**: 可以在所選時間內沒有請求時自動停止伺服器, 預設關閉.

### 執行需求

- Android 7.0 或更高版本, AutoJs6 6.8.0 或更高版本.
- 電腦上需要支援 MCP 的用戶端; USB 連線還需要 adb. 只支援 stdio 的用戶端 (例如 Claude Desktop) 需要另行安裝 [橋接程式](https://github.com/SuperMonster003/AutoJs6-MCP-Bridge).
- 介面操作與截圖需要 AutoJs6 的無障礙服務, 部分裝置上截圖還需要在手機上授權.
- 通知權限用於在任何畫面確認配對請求; Android 17 或以上還需要允許本外掛存取附近的裝置 (用於區域網路).
- 文字辨識, 條碼辨識等外掛工具需要在 AutoJs6 中安裝並啟用對應外掛.

### 常見問題

**用戶端提示 401 Unauthorized 的原因**

權杖缺失, 輸入錯誤或已輪換. 從設定頁重新複製設定; 輪換權杖後, 每個用戶端都需要改用新權杖.

**連線被拒絕時的處理**

確認抽屜中的 "MCP 伺服器" 開關已開啟. 重新連接裝置或 adb 重新啟動會清除連接埠轉送, 此時在電腦上重新執行 adb forward 指令.

**熄屏後伺服器停止的原因**

系統限制了本應用程式的電池用量時, 熄屏後可能停止伺服器. 設定頁此時會顯示提示, 點按 "電池設定" 並為 MCP Server 選擇 "無限制".

**工具未出現在用戶端中的原因**

所在分組在 "工具權限" 中已關閉, 或所需外掛未在 AutoJs6 中安裝或啟用. 啟用後用戶端的工具清單會自動更新.

各用戶端的接入方式, 工具清單與安全說明見 [專案主頁](https://github.com/SuperMonster003/AutoJs6-Plugin-MCP-Server).
