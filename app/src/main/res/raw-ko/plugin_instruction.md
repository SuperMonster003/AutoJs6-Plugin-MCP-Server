MCP Server를 사용하면 Claude Code, Cursor 같은 컴퓨터의 AI 클라이언트가 [Model Context Protocol](https://modelcontextprotocol.io)로 이 휴대폰을 조작할 수 있습니다. USB 또는 로컬 네트워크로 연결된 클라이언트는 AutoJs6를 통해 스크립트를 실행하고, 화면을 확인하고 조작하며, 스크린샷을 찍고, 작업 디렉터리의 파일을 읽고 쓸 수 있습니다. 새 클라이언트는 처음 도구를 호출할 때 휴대폰에서 확인해야 합니다.

### 시작하기

1. AutoJs6 사이드 메뉴에서 "MCP 서버" 스위치를 켜고, 처음 사용할 때는 안내에 따라 플러그인을 사용 설정합니다.
2. 해당 항목을 길게 누르거나 "플러그인 센터"에서 이 플러그인의 설정을 연 뒤, "클라이언트 설정"에서 사용하는 클라이언트의 설정을 복사해 컴퓨터의 MCP 클라이언트에 추가합니다.
3. USB로 컴퓨터에 연결한 뒤, 컴퓨터에서 "연결"에 표시된 adb forward 명령을 실행합니다 ("adb forward 명령 복사"를 탭하면 복사됩니다).
4. 클라이언트가 처음 도구를 호출하면 휴대폰에서 "허용"을 탭해 페어링을 확인합니다.

### 주요 기능

- **스크립트와 화면**: 클라이언트는 AutoJs6에서 스크립트를 실행하고 콘솔 출력을 읽으며, 접근성 노드 트리를 내보내고, 컨트롤을 찾아 탭, 입력, 스크롤하고, 스크린샷을 찍을 수 있습니다.
- **파일과 기기**: AutoJs6 작업 디렉터리의 파일을 읽고 쓰며, 앱을 실행하고, 클립보드를 읽고 쓸 수 있습니다. "공유 저장소 읽기 허용"을 켜면 갤러리와 다운로드 폴더 같은 위치도 읽기 전용으로 접근할 수 있습니다.
- **도구 권한**: 클라이언트가 쓸 수 있는 도구를 그룹별로 켜고 끌 수 있으며, 꺼진 그룹은 클라이언트의 도구 목록에 나타나지 않습니다. "파일 삭제", "좌표 제스처", "Shell 명령"은 기본적으로 꺼져 있습니다.
- **플러그인 도구**: OCR, Barcode, OpenCV 같은 플러그인을 설치하면 클라이언트가 텍스트와 바코드를 인식하고 이미지와 색상을 찾을 수 있습니다. 다른 플러그인이 선언한 도구는 "플러그인 도구"에서 켭니다.
- **등록된 스크립트**: `@agent` 주석으로 등록한 스크립트는 클라이언트에 목록으로 제공되며, 모델은 등록된 매개변수로 이를 실행할 수 있습니다. 확인이 필요한 스크립트는 실행 전에 클라이언트가 동의를 구합니다.
- **토큰과 페어링**: 클라이언트는 액세스 토큰으로 연결하며, 설정 화면에는 토큰의 마지막 4자리만 표시됩니다. "페어링된 클라이언트"에서 페어링을 해제할 수 있고, "토큰 교체" 후에는 이전 토큰이 즉시 무효가 됩니다.
- **로컬 네트워크 연결**: "로컬 네트워크 연결 허용"을 켜면 같은 네트워크의 컴퓨터가 USB 없이 연결할 수 있으며, 토큰과 페어링 확인은 그대로 적용됩니다.
- **유휴 시 자동 중지**: 선택한 시간 동안 요청이 없으면 서버를 자동으로 중지할 수 있습니다. 기본적으로 꺼져 있습니다.

### 요구 사항

- Android 7.0 이상, AutoJs6 6.8.0 이상.
- 컴퓨터에 MCP 클라이언트가 필요하며, USB 연결에는 adb도 필요합니다. stdio만 지원하는 클라이언트 (예: Claude Desktop)는 별도의 [브리지](https://github.com/SuperMonster003/AutoJs6-MCP-Bridge)가 필요합니다.
- 화면 조작과 스크린샷에는 AutoJs6 접근성 서비스가 필요하며, 일부 기기에서는 스크린샷에 휴대폰에서의 승인도 필요합니다.
- 알림 권한은 어느 화면에서든 페어링 요청을 확인하는 데 쓰입니다. Android 17 이상에서는 이 플러그인의 근처 기기 접근도 허용해야 합니다 (로컬 네트워크용).
- 텍스트 인식, 바코드 인식 같은 플러그인 도구는 AutoJs6에 해당 플러그인을 설치하고 사용 설정해야 합니다.

### 자주 묻는 질문

**클라이언트에 401 Unauthorized가 표시되는 이유**

토큰이 없거나, 잘못 입력되었거나, 교체되었습니다. 설정 화면에서 설정을 다시 복사하세요. 토큰을 교체한 뒤에는 모든 클라이언트가 새 토큰을 사용해야 합니다.

**연결이 거부될 때의 해결 방법**

사이드 메뉴의 "MCP 서버" 스위치가 켜져 있는지 확인하세요. 기기를 다시 연결하거나 adb를 다시 시작하면 포트 포워딩이 지워지므로, 컴퓨터에서 adb forward 명령을 다시 실행하세요.

**화면이 꺼지면 서버가 중지되는 이유**

시스템이 이 앱의 배터리 사용을 제한하면 화면이 꺼진 동안 서버가 중지될 수 있습니다. 이때 설정 화면에 경고가 표시되며, "배터리 설정"을 탭하고 MCP Server를 "제한 없음"으로 선택하세요.

**도구가 클라이언트에 나타나지 않는 이유**

해당 그룹이 "도구 권한"에서 꺼져 있거나, 필요한 플러그인이 AutoJs6에 설치 또는 사용 설정되지 않았습니다. 사용 설정하면 클라이언트의 도구 목록이 자동으로 갱신됩니다.

클라이언트별 연결 방법, 도구 목록, 보안 설명은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-MCP-Server)를 참고하세요.
