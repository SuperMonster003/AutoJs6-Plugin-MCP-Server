MCP Server を使うと, Claude Code や Cursor などパソコン上の AI クライアントが [Model Context Protocol](https://modelcontextprotocol.io) でこのスマートフォンを操作できます. USB または LAN で接続したクライアントは, AutoJs6 を通じてスクリプトの実行, 画面の確認と操作, スクリーンショットの撮影, 作業ディレクトリ内のファイルの読み書きができます. 新しいクライアントは, 初めてツールを呼び出すときにスマートフォンでの確認が必要です.

### はじめに

1. AutoJs6 のドロワーで "MCP サーバー" スイッチをオンにし, 初回は案内に従ってプラグインを有効にします.
2. その項目を長押しするか, "プラグインセンター" で本プラグインの設定を開き, "クライアント設定" から使用するクライアントの設定をコピーして, パソコンの MCP クライアントに追加します.
3. USB でパソコンに接続し, "接続" に表示される adb forward コマンドをパソコンで実行します ("adb forward コマンドをコピー" をタップするとコピーできます).
4. クライアントが初めてツールを呼び出したら, スマートフォンで "許可" をタップしてペアリングを確認します.

### 主な機能

- **スクリプトと画面**: クライアントは AutoJs6 でスクリプトを実行してコンソール出力を読み取り, ユーザー補助のノードツリーを書き出し, コントロールを探してタップ, 入力, スクロールし, スクリーンショットを撮影できます.
- **ファイルとデバイス**: AutoJs6 の作業ディレクトリ内のファイルの読み書き, アプリの起動, クリップボードの読み書きができます. "共有ストレージの読み取りを許可" をオンにすると, ギャラリーやダウンロードフォルダーなども読み取り専用で利用できます.
- **ツールの権限**: クライアントが使えるツールをグループごとにオン / オフでき, オフのグループはクライアントのツール一覧に表示されません. "ファイル削除", "座標ジェスチャー", "Shell コマンド" は初期状態でオフです.
- **プラグインのツール**: OCR, Barcode, OpenCV などのプラグインをインストールすると, クライアントは文字やバーコードの認識, 画像や色の検索ができます. ほかのプラグインが宣言するツールは "プラグインのツール" でオンにします.
- **登録済みスクリプト**: `@agent` コメントで登録したスクリプトはクライアントに一覧表示され, モデルは登録されたパラメーターで実行できます. 確認が必要なスクリプトは, 実行前にクライアントがあなたの同意を求めます.
- **トークンとペアリング**: クライアントはアクセストークンで接続し, 設定画面にはトークンの末尾 4 文字だけが表示されます. "ペアリング済みクライアント" でペアリングを解除でき, "トークンを更新" すると古いトークンはすぐに無効になります.
- **LAN 接続**: "LAN 接続を許可" をオンにすると, 同じネットワークのパソコンから USB なしで接続できます. トークンとペアリングの確認は引き続き必要です.
- **アイドル時に自動停止**: 選んだ時間内にリクエストがなければサーバーを自動で停止できます. 初期状態ではオフです.

### 動作要件

- Android 7.0 以降, AutoJs6 6.8.0 以降.
- パソコンに MCP クライアントが必要です. USB 接続にはさらに adb が必要です. stdio のみに対応したクライアント (Claude Desktop など) には, 別途 [ブリッジ](https://github.com/SuperMonster003/AutoJs6-MCP-Bridge) が必要です.
- 画面操作とスクリーンショットには AutoJs6 のユーザー補助サービスが必要で, 一部のデバイスではスクリーンショットにスマートフォンでの許可も必要です.
- 通知の権限は, どの画面からでもペアリング要求を確認するために使います. Android 17 以降では, 本プラグインに付近のデバイスへのアクセスも許可する必要があります (LAN 接続用).
- 文字認識やバーコード認識などのプラグインツールには, 対応するプラグインを AutoJs6 にインストールして有効にする必要があります.

### よくある質問

**クライアントに 401 Unauthorized と表示される理由**

トークンがない, 誤っている, または更新済みです. 設定画面から設定をコピーし直してください. トークンを更新した後は, すべてのクライアントで新しいトークンに切り替える必要があります.

**接続が拒否されたときの対処**

ドロワーの "MCP サーバー" スイッチがオンになっていることを確認してください. デバイスの再接続や adb の再起動でポート転送は消えるため, パソコンで adb forward コマンドをもう一度実行してください.

**画面オフ中にサーバーが停止する理由**

システムがこのアプリのバッテリー使用を制限していると, 画面オフ中にサーバーが停止することがあります. このとき設定画面に警告が表示されるので, "バッテリー設定" をタップして MCP Server を "制限なし" にしてください.

**ツールがクライアントに表示されない理由**

そのグループが "ツールの権限" でオフになっているか, 必要なプラグインが AutoJs6 にインストールまたは有効化されていません. 有効にするとクライアントのツール一覧は自動で更新されます.

各クライアントの接続方法, ツールの一覧, セキュリティの説明は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-MCP-Server) を参照してください.
